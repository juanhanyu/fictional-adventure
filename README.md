# 落选音乐候选曲归档（`archive/music-candidates`）

本分支为独立归档分支，与 `main` 主线完全隔离，专门用于保存《转生千金～到了异世界就要悠闲地生活》配乐筛选过程中未进入正式主线的 Suno 候选曲与特典音轨。

> **归档约定**：以后所有未进入 `main` 的 Suno 候选曲、备选编曲及特典版本，均统一归档至本分支 `candidates/` 目录并同步登记到下表，既保持 `main` 仓库与桌面端打包体积精简，也便于后续支线扩展、特典鉴赏或新场景复用。

所有音频均直接复用既有 Git 对象库中的原始 Blob（来源提交 `7f6e0c1`），零二次转码、100% 保留原始字节，并统一重命名为直白的情绪功能文件名。
