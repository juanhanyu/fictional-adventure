# 转生千金～到了异世界就要悠闲地生活

浏览器打开 `index.html` 即可游玩（无需服务器）。

## 操作

| 操作 | 说明 |
|------|------|
| 点击文本框 | 推进对话 / 跳过打字 |
| 底部行动栏 | 探索·交谈·修行·学习·休息·推进时间 |
| 📖 | 状态 / 技能 / 任务 / 人物好感 / 背包 / 成就 / 冰晶记忆 |
| 🗺️ | 公爵府·学院等地图移动（耗体力） |
| P / M / Esc | 面板 / 地图 / 关闭弹窗 |
| 空格·回车 | 推进文本 |

## 系统

- **时间轴**：年/月/日 + 清晨→夜晚五时段（类火山的女儿）
- **体力**：行动消耗，归零强制休息，睡眠回满
- **自由探索**：公爵府多地点、学院、旅途霁馆
- **隐藏彩蛋**：花园/图书室/酒窖/礼拜堂/露台/厨房/钟塔/花坊/纪念林/市场…
- **勇者之赐**：等阶提升时七选一（虚拟决斗 / 冰晶宫殿 / 魔战循环…）
- **虚拟决斗**：了解度≥90%可在面板发起
- **立绘差分**：希尔维亚·贝蒂·爱丽丝·索菲亚等（其余为 CSS 立绘）

## 主线快进建议

婴儿开局 →「推进时间」快进到 3 岁感知魔力 → 8 岁 → 12 岁入学 → 学院探索 → 假期转折点 / 霁馆旅途 → 结局选择。
