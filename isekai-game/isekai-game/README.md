# 转生千金～到了异世界就要悠闲地生活

浏览器打开 `index.html` 即可游玩（无需服务器）。

## 操作

| 操作 | 说明 |
|------|------|
| 点击文本框 | 推进对话 / 跳过打字 |
| 底部行动栏 | 交谈·修行·学习·课程·休息·推进季度 |
| 📖 | 状态 / 技能 / 任务 / 人物好感 / 背包 / 成就 / 冰晶记忆 |
| 🗺️ | 当前阶段的区域总览（移动会消耗体力） |
| P / M / Esc | 面板 / 地图 / 关闭弹窗 |
| 空格·回车 | 推进文本 |

## 系统

- **自动剧情**：点击「下个季度」直接推进时间；达到年龄和前置条件的章节会自动播放，并切换到对应场景，不再从菜单手选剧情。
- **区域隔离**：入学前不能前往王都材料市场；海滨别墅仅在度假剧情中出现，不与公爵府或学院自由连通；小镇与公爵府双向连通。
- **材料市场前置**：入学后，诺艾儿好感达到 **2** 才会自动触发材料市场剧情。
- **体力**：各年龄段上限为原数值的一半；升级、过日与过季均不回复体力。每季度只能休息一次，固定恢复 3 点。
- **交谈与人物排班**：交谈消耗 1 点体力。每个人每季度只会随机出现在一个合适地点，对话内容会匹配当前场景。
- **房间成长**：三岁时育婴室会通过自动剧情改建并重绘为「自己的房间」。
- **魔力透支**：魔力不足仍尝试修行时会出现确认警告；执意继续将触发生病剧情，未来一年（4 个季度）体力上限 -2。
- **勇者之赐**：等阶提升时七选一（虚拟决斗 / 冰晶宫殿 / 魔战循环等）。
- **自由探索**：公爵府、学院与旅途各有独立地点和隐藏彩蛋。

## 主线推进

从婴儿期开始使用「下个季度」推进。第一声、三姐妹、自己的房间、巴依晚宴、微服出访、入学及学院各章都会在条件满足时自动触发。学院材料市场线需要先与诺艾儿交谈，将好感提升到 2。

## 存档

`localStorage` 键：`ojousama_save_v1`。旧存档载入时会自动套用新的体力上限、区域限制与季度系统。
