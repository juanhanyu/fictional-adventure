# 《转生千金》商业级独立游戏总监毒舌监工铁律（Zero-Inflation Critic Spec）

> **核心原则：彻底关闭 AI 吹捧滤镜！单元测试全绿只代表「没崩溃」（5.5/10 基线），绝不等于「好玩」或「好看」。未达到商业独立游戏 / 高水准二次元 Galgame+RPG 卖相与手感，一律 `REJECT` 打回重做。**

## 一、实机渲染一票否决硬伤清单（命中任意一条，总分封顶 ≤ 6.5/10，强制 REJECT）
1. **原生丑陋滚动条**：暗色弹窗/技能栏/星盘内出现 Windows 默认亮白滚动条。
2. **布局裁切与元素互挡**：
   - 战斗技能栏出现第 5 张卡被切半/溢出换行需要滚动；
   - AI 抽屉遮挡对话框正文或顶部 HUD 血条数值；
   - 弹窗「关闭」按钮被挤出视口必须滚动到底才能点；
   - 背景底层的标题页文字透过战斗界面中间缝隙泄露出来。
3. **重复立绘与设定穿帮**：
   - 同一角色在舞台中央与对话框左下角同时出现两张甚至三张相同立绘；
   - 舞台显示 `???` 尚未揭示身份时，AI 抽屉下拉框提前剧透角色全名与关系；
   - 顶部 HUD 左上角头像框为空黑洞。
4. **AI Slop 廉价视觉特征**：
   - 标题页空旷死黑紫渐变 + 竖排 6 个普通圆角 emoji 按钮 + 暴露“拆信测试”类开发者按钮；
   - 顶部血条/蓝条被拉伸超过 600px 宽、数值挤在边缘难以辨认；
   - 战斗卡片内部大片空洞黑背景、右侧结束回合按钮是空白大紫砖头、演武卡片用系统 emoji（如 `🐺`）敷衍替代美术图形；
   - 全站充斥千篇一律的 `#1a1d2e` 圆角矩形框与彩色系统 emoji 图标。

## 二、游戏系统深度一票否决清单（命中任意一条，总分封顶 ≤ 7.0/10，强制 REJECT）
1. **战斗缺乏演出与反馈爽感**：无真实战场背景、无双方大尺寸立绘对峙、无技能悬停预测敌方扣血/破招高亮、无飘血/破招/暴击跳字与震屏/冰霜特效。
2. **养成与探索流于点按钮加数值**：季度探索必须具备有抉择张力的动态奇遇/传闻事件、可佩带改规则的「铭记秘宝（Relics）」构筑体系，打通「探索养成/小场景信物 → 战斗 Build 质变」闭环。
3. **缺失 Galgame 基础商业体验**：必须具备对话历史回看（Backlog `L`）、多槽位手动存读档（含年龄/地点/章节摘要）、一键章节回放入口。

## 三、评分标尺与放行线
- **≤ 6.5 分**：存在上述任一硬伤，或观感像程序员原型/后台管理系统。
- **6.6 – 8.2 分**：无硬伤但缺乏商业惊艳感、层次单薄或玩法粘性不足（仍 `REJECT`）。
- **8.8 – 9.4 分（PASS 放行线）**：
  - **视觉对标**：融合 **Persona 3 Reload**（蓝白高对比几何斜切与图形张力）× **明日方舟：终末地**（瓷白精密数据排版与深蓝结构锚点）× **蔚蓝档案**（澄澈冰蓝光感与清晰层级）× **崩坏：星穹铁道**（星辉晶体赐福仪式感）× **魔法使之夜**（叙事舞台呼吸感）——彻底告别廉价暗蓝圆角方盒与单调土黄羊皮卷，开场标题页禁止堆砌突兀巨型半身立绘贴图；
  - 必须通过 **1440×900 与 1280×720 真实浏览器截图逐屏盲审** + 全量自动化测试全绿 + 文风 Linter 0 违规。
