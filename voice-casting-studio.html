二、Colab 7-Cell 标准执行路线（可勾选留痕）

  • CELL 1探测 GPU 档位 + 挂载 Google Drive
    自动识别 H100 / A100-80G / A100-40G / API 模式，持久化 HF_HOME 权重、自定义干声 custom_refs/ 与断点缓存。
  • CELL 2拉取仓库 + 按模式安装依赖
    本地模式装 ffmpeg + sglang-omni[fishaudio]；API 模式 10 秒轻装；勾选 ENABLE_ASR_QC 启用 anime-whisper 反向质检。
  • CELL 3配置 FISH_API_KEY + 拉取 25 套参考音
    在 Colab 左侧 🔑 Secrets 配置 FISH_API_KEY（绝不写入代码），自动拉取公开元数据（零 TTS 计费）并渲染 25 位原声试听表。
  • CELL 4启动 sgl-omni serve 等 /health 就绪
    自动附带 --allowed-local-media-path 与对应显存参数，实时打印日志直至 HTTP 200（Cloud API 模式自动跳过）。
  • CELL 530 秒试音定妆墙（--scope audition · 75 条）
    25 套声线全部先出试音成品，在 Notebook 内直接点听。若有不贴合角色，改 ID 或丢入 custom_refs/<profileId>.wav 单独重跑。
  • CELL 6分档 / 全量批产（p1 / main / all）
    SHA-256 断点续传，试音已生成条目秒跳过；断线重连零重复扣费；支持填入 ONLY_IDS 精准单句返修。
  • CELL 7高 CER 抽听验收 + 导出 voice_release_pack.tar.gz
    复听 CER 警告句后，将 assets/voice/、js/voice-manifest.js 与 qa_report.json 打包归档至 Google Drive。
