第二章 三姐妹

◇

妹妹很安静。

这是我对爱丽丝最初的印象。

姐姐小时候哭起来能惊动整层楼的人，据母亲说，我也差不多。爱丽丝不一样，她很少哭，大部分时间安安静静地睡着，醒了就睁着眼睛看天花板，偶尔看看周围走动的人。

姐姐不太习惯。

“她怎么不哭？”她趴在婴儿床边，眉头皱得老紧，“是不是生病了？”

“没有生病，”母亲笑着说，“爱丽丝只是比较安静。”

“可是希尔维亚小时候会哭的！”

“每个孩子都不一样。”

姐姐还是不放心，每天都要来看好几趟，确认妹妹还在呼吸。我觉得她有点大惊小怪，但也没说什么。毕竟她是姐姐嘛。

爱丽丝三个月大的时候，我偶尔会有一种错觉：这孩子的视线，似乎会有意无意地落在我身上。

有一次我从门口走到床边，她的眼珠好像真的跟着转了一下。那双眼睛是蓝色的，清澈见底，没有婴儿常见的那层混沌，反而显得有些通透。

我停下脚步，试探性地看着她。

“……爱丽丝？”

她眨了眨眼，吐了一个泡泡，把视线挪向窗外的阳光。

……好吧，果然是错觉。这么小的孩子视力还没发育全，大概只是在追光影。

但我还是下意识多看了她两眼。毕竟在这个家里，我有种莫名的直觉——这孩子可能和我是一类人（指不爱哭闹）。

◇

爱丽丝六个月大的时候，会笑了。

头一回笑，是对着姐姐。那天姐姐正在给她表演“贝阿特丽丝大人的厉害之处”，其实就是转圈圈加手舞足蹈。跳到一半，爱丽丝笑了。

声音很小，咯咯的，像银铃。

姐姐愣住，随即眼睛一亮。

“她笑了！她对我笑了！”

从那以后，她每天都来表演。爱丽丝有时笑，有时只是安静地看着，但只要她笑了，姐姐就能高兴一整天。

“听好了！”她叉着腰对我宣布，“爱丽丝最喜欢我！因为她对我笑得最多！”

我看着她，没有反驳。虽然我觉得爱丽丝对我笑的次数也不少。

◇

爱丽丝一岁的时候，我三岁，姐姐五岁。

姐姐开始正式学习贵族礼仪，我也被安排了启蒙课程。家庭教师是个年轻女人，棕色头发扎成马尾，说话语速快，走路带风。她叫什么来着，我没太记住。反正她教的东西不难，我前世都学过，只是换了一套符号系统。

“希尔维亚大小姐学得真快！”她惊讶地说，“这么小就能认这么多字了！”

我点点头，没多解释。总不能说我前世读过十几年书吧。

课程结束后，我照例去看妹妹。爱丽丝已经会走路了，走得还不太稳。她正站在窗边，踮着脚尖，想看外面的花园。

我走过去，蹲下身。

“想出去？”

她转过头看我，眨了眨眼睛，点头。动作很小，很认真。

“走吧。”

我牵起她的手，带她去花园。

◇

花园里的花开了，开得热闹。

爱丽丝站在花坛边安静地看着。她的白发在阳光下泛着银光，和周围的花挤在一处，倒像是谁把一小片雪落进了颜料里。

我在她旁边站着，也不说话。风吹过来，带着花香。

“……漂亮。”

很小的声音。

我转头看她。那是她说的第一个词。

“你会说话了。”

爱丽丝抬头看我，脸上没什么表情，但眼睛亮亮的。

“……姐姐。”

第二个词，是叫我。

我愣了一下，然后弯起嘴角。

“嗯。”

从那以后，爱丽丝开始说话了，但话很少。姐姐每天叽叽喳喳说个不停，她就在旁边安静地听，偶尔被问到，才简短地答上一两个词。

“爱丽丝！你喜欢红色还是蓝色？”

“……蓝色。”

“为什么？”

“……好看。”

“哪里好看？”

“……天空。”

姐姐嫌她太安静，总想逗她多讲几句。但爱丽丝似乎天生就是这种性子，问一句答一句，绝不多说。

我倒觉得挺好。安静的孩子，省心。

◇

爱丽丝一岁半的时候，发生了一件事。

那天我在书房看书。说是看书，其实是在研究这个世界的魔法体系。书架上有不少相关的书，大多是我这个新手正好够用的入门读物。

魔法的核心是“亲和”。每个人天生可能拥有一种或多种属性亲和，这决定了他能学什么魔法。基础亲和就是水、火、土、风这几样，此外的都叫“赋亲和”，比如冰、雷、金属、治愈。基础亲和若天生没有，后天也能补学，只是要多花好几倍的功夫；赋亲和则没有商量——生下来有就有，没有就一辈子没有。

我打开状态面板，看自己的亲和。

```
💫 天赋亲和
   ❄️ 冰（赋亲和）
   💧 水（基础亲和）
```

冰和水。冰是赋亲和，比较稀有；水是基础亲和，很常见。两者搭在一起，应该挺协调的吧。

正想着，门被推开了。

爱丽丝站在门口，抱着一本绘本，安静地看着我。

“……姐姐。”

“怎么了？”

她走过来，把绘本放在我面前。

“……念。”

我看了她一眼，又看了看绘本。封面上画着一只兔子和一只熊，标题是《森林里的朋友》。

“你要我念给你听？”

她点点头。

“……请。”

声音很小，表情很认真。

我愣了一下。她刚才说的是“请”吧？一岁半的小孩，会用敬语？

我看着她，她也看着我，眼睛里带着一点期待。

“……好吧。”

我把她抱到腿上，翻开绘本，开始念。

爱丽丝靠在我怀里安静地听。念到有趣的地方，她会轻轻“嗯”一声；翻页的时候，她会用小手指着画面上的东西问“……这是什么”，我就一一解答。就这样念完了一整本。

“还要吗？”

她抬头看我，眼睛亮亮的。

“……还要。”

然后又补了一句：“……姐姐大人。”

姐姐大人。

我愣住了。这个称呼有点奇怪——前头多了“大人”两个字，带着敬意，又带着依赖。从一个一岁半的小姑娘嘴里说出来，有种说不出的……可爱？

“……你从哪学的这个叫法？”

爱丽丝歪了歪头，认真地想了想。

“……贝阿特丽丝大人。”

哦。姐姐的自称。所以她觉得“大人”是一种尊称。

“你不用加‘大人’，”我说，“叫姐姐就行。”

爱丽丝看着我，眨了眨眼睛。

“……可是姐姐大人，更好。”

好在哪里？

我看着她认真的小脸，一时不知道怎么反驳。

“……随你吧。”

从那以后，爱丽丝就一直这么叫我。姐姐大人。每次听到，我都有一种奇妙的感觉。

◇

三岁半的时候，我开始尝试使用魔力。

书上说，感知魔力是学魔法的第一步。每个人体内都有魔力，区别只在多少；要使用魔法，先得感知到它，再学会引导。具体方法是冥想：闭上眼睛，放空思绪，感受身体内部的流动。

对我来说，这一步毫无难度。前世我就很擅长发呆——不如说，发呆是我最喜欢的事，放空思绪对我像呼吸一样自然。

第一次冥想是在晚上。我坐在床上，闭上眼睛，呼吸放缓，思绪渐渐空白。

然后，我感觉到了。

身体里有什么东西在流动。那是一种比血液更深、更细的流动，像无数条细小的溪流，在四肢百骸之间穿行。

这就是魔力？

我试着集中注意力，把那股流动往手掌引。很慢，也很吃力，像不用手去控制一条绳子。但它确实在动。

我睁开眼睛，看自己的右手。指尖泛起一点淡淡的蓝光，一闪即逝。

但我确实看到了。

系统响了一声。

```
📜 任务完成
   ✅ 「魔力初感」
   首次成功感知并引导魔力
   🎁 奖励：经验值 ×100
```

我打开状态面板。

```
⭐ 等级：Lv.1
📊 经验值：150 / 100
```

等等，超了。

数字刚看清，面板自己刷新——

```
⭐ 等级：Lv.2
📊 经验值：50 / 200
```

升级了。生命值、魔力值、攻防都涨了一点，涨幅不大，但确实在成长。这就是系统的升级机制吗。

我正想关掉面板，世界忽然静止了。

◇

我说的是字面意思。

窗帘飘动的弧度凝固在半空，窗外夜风里的树叶一动不动，远处的虫鸣也没有了，四下里静得干干净净。

然后，眼前浮出一个新的面板。

```
🎁 勇者之赐
   恭喜！你已达到「初级」阶段
   请从以下选项中选择一项，作为你的赐予
   ⚠️ 未选择的技能将永久消失，不会再次出现
```

永久消失？

我盯着那行红色的警告看了很久。这意味着每次选择都很重：选了一个，剩下的就再也见不着了。

我继续往下看。排在第一个的技能是这样的：

```
虚拟决斗
① 可在梦中进行虚拟决斗
② 对同一个人的不同时间段，各限挑战一次
③ 需对挑战对象达到九成了解度，不限历史/现实人物
决斗中的对方是系统造出的影子，可以互相交流。
胜利可获得系统奖励——往往是被挑战者的技能，
可以是赋级别，也可以是简版，取决于难度。

注：同一人的不同时间段由系统判定
（如少年时期的剑神、全盛时期的剑神）
```

在梦里和人决斗，赢了就能拿到对方的技能。

我又把说明细看了一遍，确认自己没理解错：只要我对一个人足够了解，就能在梦里挑战他——他人生里某一个时期的他。赢了，他的本事就有机会归我。

也就是说，只要我不断把人收进图鉴，不断挑战，就能不断获得新的技能。虽然只有打赢才算数，但这个技能的上限几乎是敞着的。历史上的强者，现实中的高手，只要了解够了，都有机会。

我又去看了其余几个选项，都平平无奇，属于单一功能的好用货色，用完就到头了。只有虚拟决斗能滚雪球。

况且我现在也不缺什么保命的本事。人在公爵府，安全得很。

我伸出手，点了第一个选项。

```
✨ 你选择了：虚拟决斗（赋技能·特殊）
   技能已习得
   · 详细效果请查看技能面板
   · 当前可挑战人数：0
   · 今日剩余次数：1
```

下一秒，时间恢复流动。窗帘接着飘，树叶接着摇，虫鸣重新响起来，好像什么都没发生过。

但我知道发生了。

我打开图鉴看了一眼。父亲、母亲、姐姐、妹妹，还有几个仆人，都在里头，了解度都不高——父母的将将过半，姐姐略高一些，妹妹最低，还差得远。

九成的了解度……看来要花不少时间。而且就算了解度够了，我还得打赢才行。以我现在的本事，能打赢谁？

……先不想这个了。路要一步一步走，饭要一口一口吃。

我翻了个身，闭上眼睛。这个技能真正的价值，以后才会慢慢显出来吧。

◇

四岁。姐姐六岁，妹妹两岁。

这一年发生了几件事。

第一件事，姐姐开始系统学习魔法了。她的天赋亲和是火。

“看！”她兴奋地伸出手掌，掌心燃起一小团火焰，“我会用魔法了！”

火焰跳动着，映得她的脸红扑扑的。

“厉害吧？快夸我！”

“厉害厉害。”我敷衍道。

“你这态度！”姐姐不满，“算了，反正爱丽丝会夸我的！爱丽丝！你觉得姐姐厉害吗？”

妹妹抬起头，安静地看着那团火。

“……厉害。”

“对吧对吧！”

“……可是，希尔维亚姐姐大人也会魔法。”

姐姐一愣，转头看我。

“你会了？”

我点点头，掌心凝出一颗水球，让它在空中慢慢转。

姐姐盯着那颗水球看了一会儿，撇撇嘴。

“可是我的是火！火比水厉害！”

“水能灭火。”我随口说。

“那、那火也能把水烧干！”

我没接话。姐姐气鼓鼓地瞪了我一眼，转向妹妹。

“爱丽丝！你说谁的更厉害？”

妹妹看看姐姐，又看看我，眨了眨眼睛。

“……都厉害。”

“你这是敷衍！”

“……没有。”妹妹的表情依然淡淡的，“姐姐们都很厉害。我很……羡慕。”

最后两个字说得很轻，但我听到了。姐姐也听到了，表情一下子软下来。

“哼，算你有眼光！”她叉着腰，“放心，等你长大了，贝阿特丽丝大人会教你魔法的！”

“……谢谢姐姐。”

“不过首先要听我的话！”

“……好。”

妹妹乖巧地点头，眼睛却悄悄看向我。我对她笑了笑，她的嘴角也弯了一下。

第二件事，妹妹开始说更多的话了。

比起之前一次只吐一两个词，她现在偶尔能说完整的句子了。

“姐姐大人，今天的花开了。”

“姐姐大人，那本书我看完了。”

“姐姐大人，贝阿特丽丝姐姐又在炫耀了。”

最后一句让我忍不住笑出了声。

她说话时表情还是淡淡的，语气也平平的，内容却意外地有主意。而且我发现，她对某些事特别上心。

比如书。

有一次我在看魔法理论的书，她走过来，站在旁边，眼睛盯着书页。

“……姐姐大人在看什么？”

“魔法的书。”

“……可以教我吗？”

语气还是平平的，眼睛却忽然亮了。

“你才两岁，”我说，“看不懂吧。”

“……可以学。”

我看着她。她也看着我，那点光没有退。

“……好吧。”

我把书放到矮桌上，让她坐在我旁边，从最基础的讲起。什么是魔力，什么是亲和，什么是魔法阵。爱丽丝听得很认真，偶尔发问，问题还挺有想法。

“……所以，赋亲和学不了，只能天生有？”

“对。”

“……那怎么知道自己有什么亲和？”

“要等大一点，做测试。”

“……我想知道。”

“再等几年吧。”

她有点失望地垂下眼睛。但也只垂了一瞬，很快又恢复平时的淡然。

“……好。”

然后她的语速忽然快起来——

“那姐姐大人的水是什么颜色的？冰呢？可以用来做什么？能不能给我看看？冰和水有什么区别？是不是冰更冷？那——”

说到一半，她突然停住，脸微微红了。

“……抱歉，姐姐大人。”

“没关系。”

我看着她，觉得有点好笑。原来她也有这种时候。平时装得淡淡的，其实对感兴趣的事情热得很，只是不太会表达。

“过来。”

我伸出手，掌心凝出一颗小小的冰晶。冰晶在阳光下折出淡淡的蓝光，慢慢转着。爱丽丝的眼睛一下子亮了，这回她没掩饰，就那样亮晶晶地看着，嘴唇微微张开。

很可爱。我心想。

“冰和水，其实是同一种东西。”我让冰晶在指尖慢慢融化，水珠顺着手指滑下来，又在指尖重新冻结。“温度低了就变成冰，高了就变回水，再高——就变成看不见的气。”

“看不见的气？”

“嗯。你烧水的时候，壶嘴冒出来的白雾，其实就是水。”

“那白雾是烟做的吗？”

“是水变的。水变成气，又遇了冷，变回成小水滴，就成了你看见的白雾。”

她盯着我指尖那颗融了又冻、冻了又融的冰珠，一眨也不眨。

“那姐姐大人的冰……是把温度降下来的？”

“差不多。”

她想了想。

“那如果一直降呢？一直一直降，会变成什么？”

“会变成……”

我差点把“绝对零度”四个字说出来，赶紧咽回去。

“会变成非常非常冷的冰。硬到什么都砍得动。”

她点点头，接受了这个回答。但眼神里有一点“我觉得你省略了什么”的微妙洞察。

这孩子直觉太好了。

我又凝出一颗冰晶，比刚才那颗大些，捏成了一个——大概是兔子的形状。耳朵有点歪，严格来说更像一只耳朵被门夹过的猫。

“给你。”

她双手接过去，捧在掌心，非常小心，像接一个会碎的承诺。

“会化的。”她说。语气平平的，手却捧得更紧了一点。

“会。但我可以再做。”

“……嗯。”

她低头看着那只定义模糊的小动物。冰在她掌心的温度里渐渐变得透明，水珠顺着她的手指往下淌。

“姐姐大人。”

“嗯？”

“水往低处流，是因为什么？”

“因为……”

万有引力。不能说。

“因为大地在把水往下拉。所有东西都会被大地拉住。你跳起来会落下来，也是一样的道理。”

“大地在拉？”

“嗯。像有一只很大的、看不见的手，什么都往下拽。”

“那为什么云不掉下来？”

这个问题好。好到我得先想一想，怎么回答才不碰上那些不能说的词。

“因为云很轻，轻到大地拉不太动。就像你往井里丢一片树叶，它会浮在水面上，沉不下去。云就是天上的树叶。”

她安静了一会儿。

“那雨呢。”

“云攒多了就沉了。就像你在树叶上一直加沙子，加到一定程度——”

“就沉了。”

“对。”

“所以下雨就是云太胖了。”

“……可以这么理解。”

她点了点头，表情非常认真。

我这才后知后觉地意识到，自己刚才差点把一整节物理课搬进中世纪，还险些说出一个这个世界大概没人听说过的词。算了，反正也不是头一回。之前跟姐姐解释“为什么冬天哈气是白的”，我最后糊弄成“因为冬天的空气喜欢把呼吸变成小云朵”，姐姐不但信了，还觉得非常浪漫。

爱丽丝不一样。她不会觉得浪漫，她只会追问，追问到我的现代知识库存见底为止。

掌心的冰兔子已经化了大半，只剩一个湿漉漉的轮廓。

“再做一个吗？”我问。

她摇头，把手上的水在裙子上擦了擦，抬头看我。

“姐姐大人知道的事情好多。”

“还好吧。”

“管家说公爵家的图书馆，书多得一辈子也读不完。姐姐大人都看过吗？”

“没有。大部分很无聊。”

“那姐姐大人刚才说的那些，是从哪里知道的？”

“……想出来的。”

“想出来的？”

“嗯。发呆的时候想的。”

她又看了我一会儿。

“姐姐大人发呆的时候，在想大地为什么会拉东西。”

“偶尔。”

“……姐姐大人发呆的内容好奇怪。”

“谢谢。”

她没有再追问，心满意足地走了。裙子上多了一小片水渍，是那只兔子留下的。

◇

第三件事，我开始有意识地练习魔法。

冰和水是我的天赋亲和。水系比较基础，公爵府的藏书里教材不少；冰系是赋亲和，资料少些，但也有。

我每天抽一小段时间，练最基础的魔力控制——把魔力引到指定的地方，凝成指定的形状。系统对这种练习也记账，抠抠搜搜地记。

```
📝 练习魔力控制
   🎁 获得经验值 ×5
```

凝出水球，记得多一些；凝出冰晶，更多一些。涨得慢，但在涨。

到四岁末，我升到了 Lv.5。

```
⭐ 等级：Lv.5
📊 经验值：320 / 500
💗 生命值：35 / 35
💠 魔力值：52 / 52
✨ 魔力：18
```

状态面板还多了一个新栏目：

```
📚 已习得魔法
   💧 水球术 Lv.1 · 凝聚水球进行攻击
   ❄️ 冰晶术 Lv.1 · 凝聚冰晶进行攻击或塑形
```

进度说不上快，也谈不上慢。毕竟我才四岁。

而且，我也没有什么非要变强的理由。只是觉得既然有这个系统、有这些亲和，那就学一学，顺其自然。没有什么特别的目标，也没有什么危机感。

公爵家很安全，父母对我们很好，姐姐虽然吵，但很护着我们，妹妹安安静静的，也很可爱。

日子就这样一天天过着，平静，舒服。

◇

四岁末的某一天，父亲带回来一位客人。

那天是家族晚宴，说是庆祝什么外交上的进展，我没细听。母亲给我和姐姐换上正式的礼服，嘱咐我们要有礼貌。

“今天来的是很重要的客人，”她说，“是巴依王国的贵宾。你们要乖乖的，知道吗？”

“知道了！”姐姐回答得震天响。

我也点点头。妹妹太小，没带她。

晚宴在大厅举行。长桌铺着白桌布，摆满了精致的餐具，来宾很多，大多是我不认识的面孔。我坐在角落的位置，安静地吃东西。姐姐本来坐我旁边，很快就被几个年纪相仿的贵族小孩叫走了。我独自坐着，有点无聊。

大人们在谈正事，那些话我听不太懂，也不感兴趣。我百无聊赖地戳着盘子里的蔬菜，想着待会儿回房间继续练魔法。

“小姐一个人坐在这里？”

一个温和的声音在旁边响起。

我抬头。是个中年男人，深褐色的皮肤，眼睛细长，胡须浓密，穿一身我没见过的异域服饰——宽松的白色长袍，束着金色腰带，腰间挂了许多小瓶子。他微笑着看我，眼角的皱纹堆在一起，看上去很和蔼。

“叔叔是……？”我开口问。

“我是巴依王国来的客人，”他笑着说，声音里带一点奇怪的口音，“叫我药神就好。你父亲在那边忙着，我就四处转转，没想到看见一位小公主独自坐在这里。”

药神。

这个称呼很奇怪。但比起好奇这个，我更在意另一件事——

“您腰上挂的是什么？”

我指着那些小瓶子问。

药神低头看了一眼，笑起来。

“是药。各种各样的药。”

“什么样的药？”

“治病的、解毒的、强身的……很多种。”他从腰间取下一个小瓶子，晃了晃，“比如这个，治头疼。喝一口，头疼立刻就好。”

“真的吗？”

“真的。”

“那魔法能做到同样的事吗？”我想了想，又问，“用治愈魔法？”

药神挑了挑眉，似乎有些意外。

“治愈魔法也可以，不过路子不太一样。”他说，“魔法是引导身体自愈，药物是直接落在症状上。各有优劣。”

“那哪个更好？”

“看情况。”他笑着说，“小伤小病，药物方便；重伤，治愈魔法更有效。但最好的办法，是两者结合。”

我点点头，觉得这个回答很有道理。

“小公主对魔法感兴趣？”他问。

“嗯。”

“学了什么魔法了吗？”

“水和冰。”

“哦？”他眼睛里闪过一点光，“冰可是赋亲和，很稀有。真厉害。”

“谢谢。”

我看着他，忽然觉得这个人和其他大人物不太一样。来做客的那些贵族和官员，说话总是绕来绕去，用很多我听不懂的词，对着父亲母亲笑，对着我笑，但那种笑总隔着一层。这个人说话很直接，回答问题也很认真，没有一句“你还小，不懂”。而且他笑起来的时候，皱纹都堆在一起，像是真的开心。

“那个……”我犹豫了一下，“我还可以问问题吗？”

“当然可以。”他说，“你问什么，我都尽量回答。”

接下来的一段时间，我问了很多问题，从魔法的原理问到各国的体系差异。有些问题现在回想起来大概很幼稚，他都认真答了，偶尔还举例子。

“巴依王国的魔法和阿斯拉有什么区别？”

“我们更注重药物和魔法的结合。阿斯拉更注重纯粹的魔法战斗。”

“那您是用药物战斗的吗？”

“也可以这么说。”他笑了，“药物也是一种武器。”

“那为什么叫您‘药神’？”

“因为我做的药比较厉害。”

“有多厉害？”

“嗯……”他想了想，“大概是全世界最厉害的程度？”

我睁大眼睛看着他。

他笑着摆摆手：“开玩笑的，开玩笑的。不过确实挺厉害的。”

这时，远处传来父亲的声音，在请药神过去。

“好了，我得去那边了。”他站起身，“和小公主聊天很开心。”

“我也是。”我说。

他正要走，又停下脚步，从腰间取下一个小东西。

“对了，这个送给你。”

他递过来一个小瓶子。瓶子很小，只有我拇指那么大，里面装着淡蓝色的液体。

“这是什么？”

“小玩意，拿去玩吧。”他笑着说，“不过别打开，里面的东西有轻微刺激性。就当是个装饰品。”

我接过来。瓶身透明，淡蓝色的液体在里面轻轻晃动，灯光下泛着星星点点的微光。

很漂亮。

“谢谢。”

“不客气。”

他转身走向父亲那边。我看着他的背影，又低头看看手里的小瓶子。这个人真奇怪。明明是那么要紧的客人，却愿意花时间和一个四岁的小孩说话，还送礼物。

不过，是个好人吧。

我把小瓶子收进口袋，继续吃我的蔬菜。

```
📖 图鉴更新

👤 药神
   真名：（未知）
   所属：巴依王国
   了解度：8%
   备注：和蔼的中年男人，深褐色皮肤，留胡须，
         腰间挂着很多小瓶子。说话直接，
         会认真回答问题，不吓人。
         送了我一个装着淡蓝色液体的小瓶子。
```

那天晚上，我把小瓶子放在床头。

淡蓝色的液体在月光下泛着微光，像装着一小块天空。我不知道这是什么。但他说不要打开，我就不打开吧。反正只是个装饰品。

我闭上眼睛，慢慢睡着了。
