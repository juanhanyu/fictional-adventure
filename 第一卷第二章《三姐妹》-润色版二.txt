第一卷 公爵篇 第二章 三姐妹（润色版二）

（独立新稿，不覆盖原作，也不替换《润色版》；原稿见《转生贵族～到了异世界就要悠闲生活.txt》第一卷。本稿只做文字层面的打磨：情节、对话、人物关系统统依原作，未添加任何新的情节或情感元素——没有病娇、占有之类的内容，整章仍是姐妹日常的温馨轻喜剧。文风规则同前：去过于具体的数词，去"不是A，是B"句式，去零碎断句与罗列。原稿中一处整段重复在本稿中不出现。）


第二章 三姐妹

◇

妹妹很安静。

这是我对爱丽丝最初的印象。

姐姐小时候哭起来能惊动整层楼的人，据母亲说，我也差不多。爱丽丝不一样，她很少哭，大部分时间都在睡，睡醒了也不闹，睁着眼睛看天花板，偶尔看看旁边走动的人，看一会儿，又安安稳稳睡回去。

姐姐头一个不习惯。

“她怎么不哭？”她趴在婴儿床边，眉头拧成一团，“是不是生病了？”

“没有生病，”母亲笑着说，“爱丽丝只是比较安静。”

“可是希尔维亚小时候会哭的！”

“每个孩子都不一样。”

道理听进去了，心还是放不下。此后她每天都要来看上好几趟，凑到床边，确认妹妹还在呼吸。我觉得她大惊小怪，但没拦着。她是姐姐嘛，姐姐就有操心妹妹的特权。

爱丽丝三个月大的时候，我偶尔生出一种错觉：这孩子的目光，好像总有一下没一下地往我身上落。

有一回我从门口走到床边，她的眼珠似乎真的跟着转了转。那双眼睛是蓝的，清得见底，没有婴儿常见的那层浑浊，透亮得有点出奇。

我停下脚步，试着看她。

“……爱丽丝？”

她眨了眨眼，吐出一个泡泡，把视线挪去窗外的阳光上。

……好吧，果然是错觉。这么小的孩子眼睛还没长开，八成只是在追光。

话虽如此，我还是多看了她两眼。在这个家里，我有种莫名的直觉——这孩子大概和我是一路人（指不爱哭闹）。

◇

爱丽丝六个月大的时候，会笑了。

头一回笑，给的是姐姐。那天姐姐正给她表演“贝阿特丽丝大人的厉害之处”，说白了就是转圈圈加手舞足蹈。跳到一半，爱丽丝笑了。

声音很小，咯咯的，像银铃。

姐姐先是愣住，随即眼睛一亮。

“她笑了！她对我笑了！”

从那以后，她天天来表演。爱丽丝有时赏脸，有时只是安静地看着，但只要笑了，姐姐就能高兴一整天。

“听好了！”她叉着腰向我宣布，“爱丽丝最喜欢我！她对我笑得最多！”

我看着她，没有反驳。虽然在我印象里，爱丽丝对我笑的次数也不算少。

◇

爱丽丝一岁那年，我三岁，姐姐五岁。

姐姐开始正式学贵族礼仪，我也被安排了启蒙课程。家庭教师是个年轻女人，棕色头发扎成马尾，说话快，走路带风，名字我没能记住。好在她教的东西不难，我前世都学过，无非换了一套符号。

“希尔维亚大小姐学得真快！”她惊讶地说，“这么小就能认这么多字了！”

我点点头，没多解释。总不能说我前世读过十几年书吧。

下了课，我照例去看妹妹。爱丽丝已经会走路了，还走不太稳。她站在窗边，踮着脚尖，努力想看见外面的花园。

我走过去，蹲下身。

“想出去？”

她转过头看我，眨了眨眼，点头。动作很小，很认真。

“走吧。”

我牵起她的手，带她去花园。

◇

花园里的花开了，开得热闹。

爱丽丝站在花坛边安静地看。她的白发在阳光下泛着银光，混在一圈花里，像谁不小心把一小片雪掉进了颜料盘。

我站在她旁边，也不说话。风过来，带着花香。

“……漂亮。”

很小的声音。

我转头看她。那是她说的第一个词。

“你会说话了。”

爱丽丝抬头看我，脸上没什么表情，眼睛却亮亮的。

“……姐姐。”

第二个词，是叫我。

我愣了一下，然后弯起嘴角。

“嗯。”

从那以后，爱丽丝开始说话了，但话很少。姐姐每天叽叽喳喳讲个不停，她就在旁边安静地听，偶尔被点名提问，才简短地答上一两个词。

“爱丽丝！你喜欢红色还是蓝色？”

“……蓝色。”

“为什么？”

“……好看。”

“哪里好看？”

“……天空。”

姐姐嫌她太闷，总想逗她多讲几句。可爱丽丝天生就是这种性子，问一句答一句，绝不多给。

我倒觉得挺好。安静的孩子，省心。

◇

爱丽丝一岁半的时候，发生了一件事。

那天我在书房看书。说是看书，其实是研究这个世界的魔法体系。书架上正好有一批入门读物，对一个新手来说够用了。

魔法的核心是“亲和”。每个人天生可能带一种或几种属性亲和，带什么，能学什么。基础亲和就是水、火、土、风这几样；此外的都叫“赋亲和”，比如冰、雷、金属、治愈。基础亲和若天生缺了，后天补得上来，只是要多花好几倍功夫；赋亲和则全凭天生的运气，有就有，没有就一辈子没有。

我打开状态面板，看自己的。

```
💫 天赋亲和
   ❄️ 冰（赋亲和）
   💧 水（基础亲和）
```

冰和水。冰稀有，水寻常，搭在一起应该挺协调的吧。

正想着，门被推开了。

爱丽丝站在门口，抱着一本绘本，安静地看我。

“……姐姐。”

“怎么了？”

她走过来，把绘本放在我面前。

“……念。”

我看了她一眼，又看了看绘本。封面画着一只兔子和一只熊，标题是《森林里的朋友》。

“你要我念给你听？”

她点点头。

“……请。”

声音很小，表情很认真。

我愣了一下。她刚才说的是“请”吧？一岁半的小孩，会用敬语？

我看着她，她也看着我，眼睛里带着一点期待。

“……好吧。”

我把她抱到腿上，翻开绘本，开始念。

爱丽丝靠在我怀里安静地听。念到有趣的地方，她轻轻“嗯”一声；翻页的时候，她用小手指着画面上的东西问“……这是什么”，我就一一解答。一整本，就这样念完了。

“还要吗？”

她抬头看我，眼睛亮亮的。

“……还要。”

顿了顿，又补一句：“……姐姐大人。”

姐姐大人。

我愣住了。这个称呼有点奇怪——前头多了“大人”两个字，带着敬意，又带着依赖，从一个一岁半的小姑娘嘴里说出来，有种说不出的……可爱？

“……你从哪学的这个叫法？”

爱丽丝歪了歪头，认真想了想。

“……贝阿特丽丝大人。”

哦，姐姐的自称。所以她认定“大人”是一种尊称。

“你不用加‘大人’，”我说，“叫姐姐就行。”

爱丽丝看着我，眨了眨眼睛。

“……可是姐姐大人，更好。”

好在哪里？

我看着她那张认真的小脸，一时找不到反驳的角度。

“……随你吧。”

从那以后，爱丽丝就一直这么叫我。姐姐大人。每次听到，我都有一种奇妙的感觉。

◇

三岁半，我开始尝试使用魔力。

书上说，感知魔力是学魔法的第一步。人人体内都有魔力，差别只在厚薄；要用，先得摸到它，再学会引导。方法说来简单：冥想。闭眼，放空，去听身体里头的动静。

这一步对别人或许要练许久，对我等于免修。前世我就以发呆见长——准确地说，发呆是我最大的爱好，放空这门手艺我熟得像呼吸。

第一次冥想是在夜里。我坐在床上，闭上眼睛，呼吸放缓，思绪慢慢沉底。

然后，我感觉到了。

身体里有什么东西在流动。比血液更深，也更细，像许多条小溪在四肢百骸之间穿行，不分昼夜。

这就是魔力？

我试着把那股流动往手掌引。很慢，也很吃力，像隔着手去驯一条绳子。但它确实在动。

我睁开眼，看自己的右手。指尖泛起一点淡淡的蓝光，一闪，没了。

但我确实看见了。

系统也看见了。

```
📜 任务完成
   ✅ 「魔力初感」
   首次成功感知并引导魔力
   🎁 奖励：经验值 ×100
```

我打开状态面板。

```
⭐ 等级：Lv.1
📊 经验值：150 / 100
```

等等，超了。

数字刚看清，面板自己刷新——

```
⭐ 等级：Lv.2
📊 经验值：50 / 200
```

升级了。生命、魔力、攻防都添了一点，涨得不多，胜在真实。这就是系统的升级机制吗。

我正要关面板，世界忽然停了。

◇

我说的是字面意思。

窗帘飘起的弧度凝在半空，窗外夜风里的叶子一动不动，远处的虫鸣也没了，四下静得干干净净。

然后，眼前浮出一个新面板。

```
🎁 勇者之赐
   恭喜！你已达到「初级」阶段
   请从以下选项中选择一项，作为你的赐予
   ⚠️ 未选择的技能将永久消失，不会再次出现
```

永久消失？

我盯着那行红色的警告看了半天。意思是，每次选择都很重：拿走一个，剩下的就永远关门了。

我接着往下看。排在头一个的技能长这样：

```
虚拟决斗
① 可在梦中进行虚拟决斗
② 对同一个人的不同时间段，各限挑战一次
③ 需对挑战对象达到九成了解度，不限历史/现实人物
决斗中的对方是系统造出的影子，可以互相交流。
胜利可获得系统奖励——往往是被挑战者的技能，
可以是赋级别，也可以是简版，取决于难度。

注：同一人的不同时间段由系统判定
（如少年时期的剑神、全盛时期的剑神）
```

在梦里跟人决斗，赢了，就能把对方的本事拿过来。

我把说明又细看了一遍，确认自己没理解错：只要我对一个人足够了解，就能在梦里挑战他——挑战他人生里某一个时期的他。赢了，他的能耐就有机会变成我的。

也就是说，只要不断把人收进图鉴、不断去挑战，技能就能一件一件攒下来。前提是打得赢，可这技能的上限几乎是敞着的。历史上的强者，当世的高手，了解够了，都有份。

我又翻了翻其余几个选项，都平平无奇，属于单一功能的好用货，用一次到头。只有虚拟决斗能滚雪球。

何况我眼下也用不着什么保命的底牌。人在公爵府，安全得很。

我伸出手，点了头一个。

```
✨ 你选择了：虚拟决斗（赋技能·特殊）
   技能已习得
   · 详细效果请查看技能面板
   · 当前可挑战人数：0
   · 今日剩余次数：1
```

下一秒，时间重新流动。窗帘接着飘，叶子接着摇，虫鸣回来了，好像什么都没发生过。

但我知道发生过。

我打开图鉴看了一眼。父亲、母亲、姐姐、妹妹，还有几个仆人，都在里头，了解度都不高——父母将将过半，姐姐略好一些，妹妹垫底，还差得远。

九成的了解度……看来得慢慢攒。而且就算攒够了，还得打得赢才行。以我现在的斤两，能赢得过谁？

……先不想这个。路要一步一步走，饭要一口一口吃。

我翻了个身，闭上眼睛。这个技能真正的分量，日后自会显出来。

◇

四岁。姐姐六岁，妹妹两岁。

这一年发生了几件事。

第一件事，姐姐开始系统学魔法了。她的天赋亲和是火。

“看！”她兴奋地伸出手掌，掌心燃起一小团火焰，“我会用魔法了！”

火苗跳动，映得她满脸红光。

“厉害吧？快夸我！”

“厉害厉害。”我敷衍道。

“你这态度！”姐姐不满，“算了，反正爱丽丝会夸我！爱丽丝！你觉得姐姐厉害吗？”

妹妹抬头，安静地看着那团火。

“……厉害。”

“对吧对吧！”

“……可是，希尔维亚姐姐大人也会魔法。”

姐姐一愣，转头看我。

“你会了？”

我点点头，掌心凝出一颗水球，让它在空中慢慢转。

姐姐盯着看了一会儿，撇撇嘴。

“可是我的是火！火比水厉害！”

“水能灭火。”我随口说。

“那、那火也能把水烧干！”

我没接话。姐姐气鼓鼓地瞪我一眼，转向妹妹。

“爱丽丝！你说谁的更厉害？”

妹妹看看姐姐，又看看我，眨了眨眼睛。

“……都厉害。”

“你这是敷衍！”

“……没有。”妹妹的表情依然淡淡的，“姐姐们都很厉害。我很……羡慕。”

最后两个字说得很轻，但我听见了。姐姐也听见了，脸色一下子软下来。

“哼，算你有眼光！”她叉着腰，“放心，等你长大了，贝阿特丽丝大人亲自教你魔法！”

“……谢谢姐姐。”

“不过首先要听我的话！”

“……好。”

妹妹乖巧点头，眼睛却悄悄瞟向我。我冲她笑了笑，她的嘴角也跟着弯了一下。

第二件事，妹妹的话变多了。

比起从前一次只吐一两个词，她现在偶尔能说完整的句子。

“姐姐大人，今天的花开了。”

“姐姐大人，那本书我看完了。”

“姐姐大人，贝阿特丽丝姐姐又在炫耀了。”

最后一句害我笑出了声。

她说话时表情照旧淡淡的，语气照旧平平的，内容却很有主意。而且我发现，她对某些事特别上心。

比如书。

有一次我在看魔法理论的书，她走过来，站在旁边，眼睛盯着书页。

“……姐姐大人在看什么？”

“魔法的书。”

“……可以教我吗？”

语气平平，眼睛却忽然亮了。

“你才两岁，”我说，“看不懂吧。”

“……可以学。”

我看着她。她也看着我，那点光没有退。

“……好吧。”

我把书放到矮桌上，让她坐在我旁边，从最基础的讲起。什么是魔力，什么是亲和，什么是魔法阵。爱丽丝听得认真，偶尔发问，问题还挺有想法。

“……所以，赋亲和学不了，只能天生有？”

“对。”

“……那怎么知道自己有什么亲和？”

“要等大一点，做测试。”

“……我想知道。”

“再等几年吧。”

她有点失望，眼睛垂了一瞬，很快又恢复平时的淡然。

“……好。”

然后她忽然连珠炮似的——

“那姐姐大人的水是什么颜色的？冰呢？可以用来做什么？能不能给我看看？冰和水有什么区别？是不是冰更冷？那——”

说到一半，她猛地刹住，脸微微红了。

“……抱歉，姐姐大人。”

“没关系。”

我看着她，觉得有点好笑。原来她也有这种时候。平时端得淡淡的，其实对感兴趣的事热得很，只是不太会表达。

“过来。”

我伸出手，掌心凝出一颗小小的冰晶。冰晶在阳光下折出淡淡的蓝光，慢慢转着。爱丽丝的眼睛一下子亮了，这回她懒得掩饰，就那样亮晶晶地看着，嘴唇微微张开。

很可爱。我心想。

“冰和水，其实是同一种东西。”我让冰晶在指尖慢慢融化，水珠顺着指缝滑下来，又在指尖重新冻住。“温度低了是冰，高了是水，再高——就成了看不见的气。”

“看不见的气？”

“嗯。你见过烧水吧，壶嘴冒出来的白雾，其实就是水。”

“那白雾是烟做的吗？”

“是水变的。水化成气，又遇了冷，缩回成小水滴，就成了你看见的白雾。”

她盯着我指尖那颗化了又冻、冻了又化的冰珠，一眨不眨。

“那姐姐大人的冰……是把温度降下来的？”

“差不多。”

她想了想。

“那如果一直降呢？一直一直降，会变成什么？”

“会变成……”

“绝对零度”四个字到了嘴边，被我咽了回去。

“会变成非常非常冷的冰。硬到什么都砍得动。”

她点点头，接受了。但那眼神分明在说：我觉得你省略了什么。

这孩子直觉太好了。

我又凝出一颗冰晶，比刚才的大些，捏成了一个——大概是兔子。耳朵有点歪，严格来说更像一只耳朵被门夹过的猫。

“给你。”

她双手接过去，捧在掌心，小心得像接一个会碎的承诺。

“会化的。”她说。语气平平的，手却捧得更紧了。

“会。但我可以再做。”

“……嗯。”

她低头看那只定义模糊的小动物。冰在她掌心的温度里渐渐透明，水珠顺着指缝往下淌。

“姐姐大人。”

“嗯？”

“水往低处流，是因为什么？”

“因为……”

万有引力。不能说。

“因为大地在把水往下拉。所有东西都被大地拉住。你跳起来会落下来，一个道理。”

“大地在拉？”

“嗯。像有一只很大很大的、看不见的手，什么都往下拽。”

“那为什么云不掉下来？”

这个问题好。好到我得先想一想，怎么答才不踩到那些不能说的词。

“因为云很轻，轻到大地拉不太动。就像你往井里丢一片树叶，它会浮在水面上，沉不下去。云就是天上的树叶。”

她安静了一会儿。

“那雨呢。”

“云攒多了就沉了。就像你在树叶上一直加沙子，加到某个份上——”

“就沉了。”

“对。”

“所以下雨就是云太胖了。”

“……可以这么理解。”

她点点头，表情无比认真。

到这时我才后知后觉：自己刚才差点把一整堂课搬进中世纪，还险些说漏一个这个世界八成没人听过的词。算了，反正有前科。之前跟姐姐解释“为什么冬天哈气是白的”，我最后糊弄成“因为冬天的空气喜欢把呼吸变成小云朵”——姐姐深信不疑，还觉得浪漫极了。

爱丽丝不一样。她不吃这套。她只追问，一直追问到我的现代知识库存见底为止。

掌心的冰兔子已经化掉大半，只剩一个湿漉漉的轮廓。

“再做一个吗？”我问。

她摇头，把手上的水在裙子上擦了擦，抬头看我。

“姐姐大人知道的事情好多。”

“还好吧。”

“管家说公爵家的图书馆，书多得一辈子也读不完。姐姐大人都看过吗？”

“没有。大部分很无聊。”

“那姐姐大人刚才讲的那些，是从哪里知道的？”

“……想出来的。”

“想出来的？”

“嗯。发呆的时候想的。”

她又端详了我一会儿。

“姐姐大人发呆的时候，在想大地为什么会拉东西。”

“偶尔。”

“……姐姐大人发呆的内容好奇怪。”

“谢谢。”

她没有再追问，心满意足地走了。裙子上多出一小片水渍，是那只兔子留下的。

◇

第三件事，我开始有意识地练魔法。

冰和水是我的天赋亲和。水系基础，府里藏书教材管够；冰系是赋亲和，资料少些，但翻得出来。

我每天抽一小段时间，练最底层的功夫——把魔力引到指定的地方，凝成指定的形状。系统对这种练习也记账，抠抠搜搜地记。

```
📝 练习魔力控制
   🎁 获得经验值 ×5
```

凝出水球，多记一点；凝出冰晶，再多一点。涨得慢，好在一直在涨。

到四岁末，我升到了 Lv.5。

```
⭐ 等级：Lv.5
📊 经验值：320 / 500
💗 生命值：35 / 35
💠 魔力值：52 / 52
✨ 魔力：18
```

状态面板还添了个新栏目：

```
📚 已习得魔法
   💧 水球术 Lv.1 · 凝聚水球进行攻击
   ❄️ 冰晶术 Lv.1 · 凝聚冰晶进行攻击或塑形
```

进度说不上快，也谈不上慢。毕竟我才四岁。

再说，我也没有非变强不可的理由。既然有系统、有亲和，那就学着玩，顺其自然。没有目标，也没有危机感。

公爵家很安全。父母对我们很好，姐姐吵归吵，护起妹妹来一马当先，最小的这个安安静静，看着就让人心软。

日子就这么一天天过，平静，舒服。

◇

四岁末的某一天，父亲带回一位客人。

那晚是家族晚宴，说是庆贺什么外交上的进展，我没细听。母亲给我和姐姐换上正式的礼服，再三嘱咐要有礼貌。

“今天来的是很重要的客人，”她说，“巴依王国的贵宾。你们要乖乖的，知道吗？”

“知道了！”姐姐应得震天响。

我也点点头。妹妹太小，没带她。

晚宴设在大厅。长桌铺着白桌布，餐具摆得一丝不苟，来宾乌泱泱一片，大多是我不认识的脸。我挑了角落的位置，安静地吃东西。姐姐本来坐我旁边，没坐多久就被几个年纪相仿的贵族小孩喊走了，剩下我一个人，百无聊赖地戳着盘里的蔬菜，盘算着待会儿回房继续练魔法。

“小姐一个人坐在这里？”

一个温和的声音在旁边响起。

我抬头。是个中年男人，深褐色的皮肤，眼睛细长，胡须浓密，穿一身我没见过的异域服饰——宽松的白色长袍，束着金色腰带，腰间挂了一圈小瓶子。他微笑着看我，眼角的皱纹堆在一起，瞧着很和气。

“叔叔是……？”我开口问。

“我是巴依王国来的客人，”他笑着说，口音有点怪，“叫我药神就好。你父亲在那边忙，我就四处转转，没想到撞见一位小公主独自坐在这里。”

药神。

这称呼可真新鲜。但比起纠结这个，我更在意另一件事——

“您腰上挂的是什么？”

我指着那些小瓶子问。

药神低头看了一眼，笑起来。

“药。各种各样的药。”

“什么样的药？”

“治病的、解毒的、强身的……多了去了。”他从腰间摘下一个小瓶子，晃了晃，“比如这个，治头疼。喝一口，立刻见效。”

“真的吗？”

“真的。”

“那魔法能做到同样的事吗？”我想了想，又问，“用治愈魔法？”

药神挑了挑眉，似乎有些意外。

“治愈魔法也可以，不过路子两样。”他说，“魔法是引导身体自己好起来，药物是直接落在症状上。各有各的长处。”

“那哪个更好？”

“看情况。”他笑着说，“小病小痛，药物省事；伤筋动骨，魔法管用。不过最好的法子，是两头一起用。”

我点点头，觉得这话在理。

“小公主对魔法感兴趣？”他问。

“嗯。”

“学了什么了吗？”

“水和冰。”

“哦？”他眼里闪过一点光，“冰可是赋亲和，稀罕东西。真厉害。”

“谢谢。”

我看着他，忽然觉得这个人和别的大人物两样。来做客的那些贵族官员，说话总绕着弯，净用些我听不懂的词，对着父亲母亲笑，对着我笑，那种笑总隔着一层什么。这位倒好，问什么答什么，一句“你还小，不懂”都没有。而且他笑起来皱纹全堆在一处，像是真开心。

“那个……”我犹豫了一下，“我还可以问问题吗？”

“当然。”他说，“你问什么，我尽量答。”

接下来的一段时间，我把攒下的好奇倒了个空，从魔法的原理问到各国的体系差异。有些问题现在回想大概幼稚得很，他都认真答了，偶尔还举个例子。

“巴依王国的魔法和阿斯拉有什么区别？”

“我们讲究药和魔法合着用。阿斯拉偏爱纯粹的魔法战斗。”

“那您是用药物战斗的吗？”

“也可以这么说。”他笑了，“药也是一种武器。”

“那为什么叫您‘药神’？”

“因为我做的药比较厉害。”

“有多厉害？”

“嗯……”他想了想，“大概是全世界最厉害的程度？”

我睁大眼睛。

他笑着摆摆手：“开玩笑的，开玩笑的。不过确实挺厉害的。”

这时，远处传来父亲的声音，在请药神过去。

“好了，我该过去了。”他站起身，“和小公主聊天很开心。”

“我也是。”我说。

他正要走，又停下，从腰间取下一个小东西。

“对了，这个送给你。”

他递来一个小瓶子。瓶子很小，也就我拇指那么大，里头装着淡蓝色的液体。

“这是什么？”

“小玩意，拿去玩吧。”他笑着说，“别打开就行，里头的东西有点刺激性。就当个装饰品。”

我接过来。瓶身透明，淡蓝色的液体轻轻晃着，灯光下泛出星星点点的微光。

很漂亮。

“谢谢。”

“不客气。”

他转身朝父亲那边去了。我看着他的背影，又低头看看手里的小瓶子，心想这个人真奇怪——那么要紧的客人，居然肯花工夫陪一个四岁的小孩说话，走前还塞份礼。

不过，是个好人吧。

我把小瓶子收进口袋，继续吃我的蔬菜。

```
📖 图鉴更新

👤 药神
   真名：（未知）
   所属：巴依王国
   了解度：8%
   备注：和蔼的中年男人，深褐色皮肤，留胡须，
         腰间挂着很多小瓶子。说话直接，
         问什么都认真答，不吓人。
         送了我一个装着淡蓝色液体的小瓶子。
```

那天晚上，我把小瓶子搁在床头。

淡蓝色的液体在月光下泛着微光，像装着一小块天空。里头装的什么，我不知道。他说别打开，那就不打开吧。反正只是个装饰品。

我闭上眼睛，慢慢睡着了。
