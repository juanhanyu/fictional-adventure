转生千金～到了异世界就要悠闲地生活

第一卷 间章　月蚀之日

（本篇为间章新增稿，不改动原稿；建议插入位置：第一卷第三章《每一天》与第四章《决斗》之间，时点在主角十岁前后。）


◇

十岁那年的秋天，领地里开始流传一个说法。

说是入夜以后，不要在巷子里跟穿白衣服的人搭话。搭了话的人，回家就要大病一场，病得脸颊一天比一天瘪，嘴唇白得没了血色，大夫们查不出缘由，只说是虚劳，让好生养着，养着养着人就没了。

起初只是酒馆的醉话。后来外庄的佃户来报，说羊群接连遭了祸，好几只母羊倒在圈里，浑身上下找不着伤口，就是没了血。再后来，城西磨坊家里帮工的小伙子也倒了，症状同传闻里说得一模一样。

这话传进公爵府，是饭桌上姐姐先说起来的。她讲得眉飞色舞，说什么"白色的客人""月圆之夜敲窗"，讲得自己先打了个寒噤，然后嘴硬说贝阿特丽丝大人怎会怕这个。母亲放下筷子让她少说两句，父亲皱着眉没作声。

我本来只当个故事听。领地里闹传闻，跟刮季风一样，年年都有新花样。

直到那天夜里，系统忽然响了一声。

```
📜 新任务
   「月下的客人」
   📝 查明领地内"吸血鬼传闻"的真相
   ⚠️ 评估：目标危险度远高于当前等级
   🎁 奖励：经验值，？？？
   ⏰ 期限：无
```

我盯着面板上"远高于当前等级"那一行看了半天。系统发任务素来爱凑热闹，可它在危险度这一项上从没说过大话。它说远比我强，那就是真的远比我强。

可话又说回来——从我窗台上望出去，山脚下就是那片正在闹鬼的领地。这种事摊在自己屋檐底下，总不能装聋。

◇

我没有立刻往外跑。我先做的是两件事。

第一件，进冰晶宫殿，把这个秋天以来存进去的画面翻出来重看。冰镜一面一面亮着，我像个坐在库房里的管账先生，把人手不够时随手记下的流水账重新誊了一遍：佃户进府报信时搓着手说的每句话，饭桌上姐姐学的那些醉汉腔，我去外庄查看羊圈那天的情形。

画面是不会骗人的，骗人的是记性。重看一遍，几处被我当场放过的东西浮了上来——出事的日子零零散散，可把它们按日子排开，出事的当夜，天上挂的多半是圆月，或者将圆未满的月亮。报信的人里换了几拨面孔，讲来讲去，源头却总绕着城西那一带打转。

第二件，把这个排法又核了一遍。狼吃羊不挑日子，可月亮圆的时候出事多，这就不像野兽的做派，倒像日子对"它"有什么讲究。

眼下的一切还都够不上证据，只能算风向。可风向值得再探一探。我盘算着找个由头再去城里转转，还没动身，父亲先把我叫去了书房。

书房里没点几盏灯，父亲坐在桌子后面，面前摊着一卷领地文书。他难得地没有绕弯子。

"最近领地里的风言风语，我都知道了。"他说，"从今天起，你和姐姐妹妹，没有要紧事不要出府。"

我问为什么。

他停了一下，像是在斟酌能跟我这个十岁的女儿讲到哪一步，最后只说了句："有些东西，沾上了就甩不脱。听父亲的话。"

我应了一声是。出门的时候我回头看了一眼，他还盯着桌上那卷文书，拇指在纸沿上摩挲着，一下，又一下。父亲这个人泰山崩于前不改色，可他摩挲纸沿的动作我认识——家里谈最棘手的公务时他就这样。

他心里有事，而且那件事比我听到的传闻要沉得多。

回到房间，我打开系统，让它替我算了笔账。

```
📊 行动评估
   · 方案「秘密调查」可行性：低
     公爵府次女的外出记录过多，长期隐瞒可行性差
     一旦被目标察觉，随行人员过少，风险不可控

   【分支】坚持调查（建议转为"公开调查"，争取监护人知情）
            就此作罢
```

我站在窗前想了很久。作罢的话，任务黄了，命保住了，可那个在月圆夜敲窗的东西还留在自己的领地里，有一日没一日地敲别人家的窗。坚持的话，系统把话说得很明白：一个人闷头查是查不动的。

那晚我翻来覆去，最后想通了一件事。

我要查。可我得先认输——承认我一个十岁的孩子兜不住这件事，然后把它交一半出去，交给这个府里兜得住它的人。

◇

第二天一早，我带着整理好的那页纸去了书房。纸上没有一句怪力乱神，只有排开的日子、出事的地段、和对不上的几处关节。父亲一页看下来，看我的眼神变了几次，从"你又胡闹什么"变成"这东西哪来的"，最后停在一个我读不太透的地方。

"这是我排的。"我说，"我要把这件事查清楚。我不打算瞒着您查，我要接着查。您要拦，我今天就把这页纸烧了，可我还是想请您让我查下去。"

书房里静了很久。

"你像谁啊。"父亲忽然说了这么没头没尾的一句。然后他把那页纸押在桌案上，站起身，走到窗边背对着我，"你两个叔叔和姑姑小时候，也都是这股不撞南墙不回头的劲。"

他转了回来，又成了那个说一不二的公爵。

"查可以。从今往后，你出府，随行侍卫加到三名，连去花园里挖土都得有人跟着。有几处地方你不许去，我列给你。再有——"他顿了顿，"查到什么，先回来说，不许自作主张。"

我应下了。这买卖比我预想的好得多。

当天，我的影子就变成了四条。多出来的三个人里，为首的是个上了年纪的老侍卫，叫巴特，脸上刻着风霜，腰间那柄剑的鞘都磨出了包浆，据说是跟着父亲年轻的年月里见过真阵仗的。另一个是女剑士林恩，话不多，眼睛很利，据说是家兵里身手排得上号的。垫底那个叫多特，年轻，嘴碎，热心得有些冒失，第一天跟着我就在后头小声嘀咕，说二小姐查什么案子，小孩子家家的贪玩罢了。

这话没过几天就被他自己咽了回去。

◇

带着三条尾巴查案，起初我以为会碍事，实际操作下来才发现，这是给我送了三双不用白不用的手。

巴特替我去问话。上了年纪的老侍卫往酒馆门口一坐，不用粗声大气，掌柜的自然就愿意跟他掏心窝子，哪里又倒了人，谁家请了大夫，比我自己瞎问快得多。林恩替我跑腿丈量，哪条巷子通哪条巷子，夜里更夫换岗的脚程，她回来画成图，比我纸上谈兵实在。多特被我打发去各家药铺闲聊，他那张碎嘴在这种场合居然也算物尽其用。

消息一点一点拢回来，我那页纸越写越满。拢到后来，文书上可以勾掉的怀疑对象一个一个被划去，剩下的一些线索，开始不听话地往同一个方向歪。

城西那位格雷医师。

这个人是近一年才在城里立稳脚跟的，医术好，收诊金随和，穷人家去求他，他常常连钱都肯少收。城外倒下的佃户、磨坊的帮工、巷子里害了虚劳的人家，桩桩件件，头一个上门诊治的都是他——这本来无可指摘，城里医术拿得出手的大夫拢共就那么几位，谁先被请到都不稀奇。

可有几处对不上。

多特闲聊时听药铺伙计讲过一嘴，格雷医师给这些病人开的方子里，有一味"以血为引"的旧法，说是放几滴病血做药引，引出瘀血。行医的规矩我不懂，可冰晶宫殿里存着的那几段画面会替我记得：倒在巷子里的更夫被抬去药庐那天，我去得晚，只看到担架一角，当时没留意，回看重放才发觉，担架上那人手腕内侧贴着一小方棉布，棉布底下若隐若现，是同一种取过血的痕迹。

还有一回，母亲染了些风寒，府里图省事，请的也是他。我在厅里同他打过一次照面。他给母亲搭脉，手指搭上去很快就挪开了，报出来的诊词却准得吓人，连母亲自己都没留神的旧年旧伤也在其列。事后母亲夸他神乎其技。

我把那一小段画面翻来覆去看了几遍。他哪里用得着搭脉——他是"看"出来的。那双手与其说在诊脉，不如说在做什么别的丈量。而从头到尾，厅里那壶茶，他没有沾过一口。巴特意会神地补了一句：这位医师在哪家出诊，也从不吃主人家的一粒米、一滴水，人人都夸他规矩。

规矩。一个人靠吸血续命的话，五谷杂粮对他就确实是多余的礼节了。

至此，方向有了，可还差一样东西——差的那个东西叫证据。他行医的光明正大，行医的人接触血是天经地义，他做什么都在明处，这才是最难缠的地方。就像一粒盐融进了汤里，人人都喝得下去，谁也没法指着汤说盐在哪里。

夜里我对着系统嘀咕：这个人藏在每一个环节里，又哪里都不在。

系统的回答一向来得慢，这一回倒快。

```
📖 图鉴更新
   👤 格雷（医师）
   · 种族：？？？（高度疑似：血族）
   · 血族：以月华为魔力之源，吸食血液维系存续的存在
   · 不惧日光；被吸食鲜血者将持续损耗生气，至濒死之际，
     有一定概率被血族操控，沦为傀儡
```

我盯着"沦为傀儡"那四个字看了很久，后背凉了一层。怪不得那些病人日渐枯瘦却查不出病，怪不得他说要"养着"——他在养他走动的储粮，养到最后一息尚存的人，还能剩一副听他差遣的空壳。

◇

隔了几日，我打着陪多特看诊的由头，领着三条尾巴去了一趟他的药庐。多特前几日守夜着了凉，咳嗽一直没断根，这个由头现成得很。

药庐里排着长队，乡里乡亲挤了半间屋子。格雷医师在里面忙得脚不沾地，见一个病人能直呼其名，问得清人家上回的药吃到第几帖，婆娘的风湿在左腿还是右腿。轮到我们，他还记得多特，笑着说这位小哥前阵子抓过两回药了，年轻人火气旺，夜里头少吹风。多特被他哄得脸红脖子粗，抓药的时候还一个劲跟我夸他。

我坐在一旁闲看。看他搭脉，看他开方，看他把人送出门口。一切都有条有理，温热周到，任谁来看都只想得起"仁心"两个字。我故意在他路过的时候打了个岔，提起自己近来睡不安稳，月圆的那几夜尤其容易惊醒，问先生可有安神的方子。

他脚步停了一瞬。那一瞬极短，换作常人根本无从问起。

"月圆惊梦，多是心血不足。"他转回头来笑，"小姐金枝玉叶，何苦忧心这些。开一味酸枣仁汤，睡前温服便是。"

答得滴水不漏。可他开方的时候，我多留了个心眼瞟他的案头——那上头摊着一册翻旧的历书，边角磨得起了毛，页页都画着些只有他自己认得的圈点。历书是行医的人也用得着的东西，可我见过药铺的历书，人家画的是节气与药期，他画的圈却疏疏落落，尽落在些无月的晦日和日月交会的日子上。

临走，他抓了把甘草糖塞给多特，又拈了一颗递与我。我接了，当着他的面含进嘴里，甜丝丝的，带着药材的回甘。他看着我咽下去了，才笑着转身去忙。

出了药庐的门，我把方才那一整段路原封不动存进了冰晶宫殿——那颗糖化在糖水里的味道，历书上那些圈的位置，他称呼每个病人时的口吻，一样都没落下。冰镜里存的东西不打折扣。往后人脑记不牢的地方，就让冰来记。

回府的路上我的心情很复杂。若是我的怀疑出了错，城里就是平白多了一位大夫替我瞧病；若是错不了——那他塞进我嘴里的，就远不止一颗糖那样简单。

◇

证据拿不到，那就让他自己走出来。

这个念头落定之后，我花了几天布置。布置的由头要他给，犯不着我给——我借父亲的名义透出风去，说公爵府清点旧藏，寻出一批前朝巫术文书，不日将当众焚毁，里头有记载着"克制血族古法"的孤本。这话假得漏洞百出，真正的孤本谁舍得烧。可信不信由他：他若清白，这话传到他耳朵里只当笑话；他若真有问题，他赌不起那个"万一"，他必须在那堆纸烧掉之前做点什么。

鱼饵放下去的同时，线也得收好。焚书的日子是个虚日子，真正做这个局的地点，父亲替我圈定在了旧书库。家兵里最能打的几个人那几日陆续换了便装，书库周遭的岗哨暗暗换了整整一班。

饵落水后的头几日，没有动静。

非但没有动静，多特从药铺带回来的话还让我心凉了半截：格雷医师这两日不收新病人了，药庐里在清库，逢人只说自己进了一批货要回家乡去盘账，归期不定。父亲听了这话，当晚就寻我谈：要不趁他还未动身，直接调兵拿人。罪名不好安，可宁可错拿，也不能放跑了。

我咬着嘴唇想了很久。拿人需要证据，如今能摆上桌面的只有"行医居心可疑"这种要吵上公堂的软账，凭这个拿人，万一当场逼他现形，药庐地处闹市，且不说拿不拿得下，先伤的就是一整条街的百姓。放他去动那批"孤本"呢？他若警惕，大可远走高飞，等风头过了再另换一个地方从头做起，一样是输。

两条路都走不通的时候，我忽然明白了一件事：这个局从搭起来那天起，比的就成了谁耗得起——耗不住的那一个出局。他在耗我的耐心，耗到我自己露出马脚——或者干脆认输转进。那我就只能比他更沉得住气，把饵做得再真一点，真到他舍不得走。

翌日我让父亲把风声再放细了一档：焚书的仪程定了，公爵府还特意请下了城中教堂的老神官，要在点火之前当众"净化"这批文书。这一句是点睛——他若清白，净化与否与他何干；他若沾着那门血脉，"教会当众过手"这几个字就足够让他夜里坐不住。那批文书也不再是空架子，父亲从府库最底下翻出一摞真的前朝禁档做瓤，封面做旧，气味做旧，往书库里一摆，连我这个知情的都想上去翻一翻。

最后落的一子是我自己。我放出话去：焚书前要亲自把那批文书清点造册，这几日午后都在旧书库里。话传出去，人人都说这是二小姐雅癖，只有他听得懂话里另一层意思——守着书的那个人，年方十岁，出门只带三条尾巴。

饵下到这个份上，只剩等了。

做这些事的间隙里我停了停，忽然意识到自己在做什么——我在拿"他可能不知道万法皆灰的孤本存在吗"这套话术，去钓一个捏着全城病人生死的什么东西。万一他不上钩呢？万一他上了钩，钩住的是别人家的命呢？

系统安安静静浮出一行字。

```
📜 任务「月下的客人」——分支确认
   当前路径：设伏
   备选路径：放弃（已锁定，不可更改）
```

它倒是把退库收据都替我撕了。也好，省得我再动摇。


◇

动手的那晚离"焚书"还有几日。夜里没有月亮，是月末，挑这样的日子是我坚持的——以月华为食的东西，无月的夜里最饿，也最弱。

他是子时来的。从书库顶上那个只有我知道没锁严的气窗进来的，一身灰衣，落地没有声响，为的就是那一架"前朝巫术文书"。书架上自然没有孤本，只有一层我父亲亲手布下的、看不见的暗红收束。

网收紧的一瞬间，天翻地覆。

那东西的皮囊当场就撑裂了——灰衣底下站起来的，是个高得反常的影子，皮肤白得像浸了水的纸，十指弯成钩，嘴里的犬齿探出嘴唇。他反手一挣，十来个死死拽着收束索的家兵跟着踉跄。我第一次亲眼见到父亲的魔法全开的模样：暗红色的光贴着地面游走，像烧红的铁丝扎进泥里，一层一层缠上去，那影子每挣开一层，地面就裂开一道。

他没有逃。他就站在原地挣，一边挣一边笑，笑声尖得刮人耳膜。

"这么点大的地方，也配关我？"

困兽之斗持续了很久。到最后，是父亲用整面塌下来的书库东墙把他压在底下，封魔的镣铐扣上双腕，他才终于不动了。镣铐闭合的那一刻，我远远瞧见他仰起头，看了一眼窗外。

窗外没有月亮。可他那个仰头的姿势很奇怪，不像败军之将看天，倒像赶路的人在核对时辰。

这个细节我当晚就记进了冰晶宫殿，可惜我那时没有读懂。

◇

处置办得很快。血族伤了多少条人命，桩桩件件都有苦主，公爵府的判决根本不需要拖：公开处死，以儆效尤。日子定在数日后的正午，地点在城中广场，全院架了柴，说是要用日头最盛的火送这东西上路。

城里万人空巷。开会那天我也在，父亲把判罚念完，问大家还有什么要说的，底下一片叫好，只有我望着台上那个垂着头的灰影子出了会儿神。他被押上来的时候安安静静，谁也看不出几日前书库里那场恶斗，倒像个认命的教书先生。从头至尾他都很配合，配合得近乎温顺。

现在回想起来，书里写过这种温顺。被拖上岸的鱼最安静的片刻，是它听明白了水流的方向。

姐姐嚷嚷着要去看行刑，被母亲按住了。妹妹从始至终没问一句。我自己本该去看个究竟，临出门却又改了主意——说到底我怵那样的场面，反正镣铐加身，左右只是走个过场。父亲带着府兵在广场坐镇，我便索性打道回府，心安理得。

任务结算的面板，在我脑子里已经提前开始打了草稿。那时还是大白天，日头明晃晃挂在天正中，把回府那条林荫道的影子都晒得短短的。

变故来的时候，先变的是光。

我正跟多特有一搭没一搭地说着话——他在跟我赔罪，郑重其事地把第一天的"贪玩"论调收了回去，说往后二小姐办案，他第一个报名——天上的太阳忽然缺了一角。

起先没有人当真。缺的那一角慢慢扩大，光色跟着一分一分地暗下去，像有人在天外拧一盏灯。巴特第一个停下脚，仰头看了一眼，脸色变了。

"回府！"他只说了一个字。

影子在我们的脚边拉长、发蓝，最后连轮廓都淡去。正午的半天里，头顶升起了一个漆黑的圆，圆外箍着一圈惨白的冕。四下里的鸟雀全都噤了声。

系统在我脑海里炸响，是它从来没有用过的调门。

```
⚠️ 警告：高能反应急速接近
   方向：城中广场
   危险评估：无法计算（建议：立刻规避）
```

我胸口的汗毛倒竖起来。电光石火之间，冰晶宫殿里那册摊在案头的历书亮了起来——那些我看不懂的圈点，落的全是日月交会的宫位。我读懂了，读懂了他仰头核对的那个时辰：这位医师早就知道今天正午有日蚀，他就是掐着这一天，才肯那样安安静静地束手就擒。镣铐锁得住他血里的魔力，锁不住天上的月亮。日蚀一合，等于午夜提前到了正午，他借的是整个月亮的力。

广场那边远远地起了喧哗，隔着大半个城，闷闷地滚过来，像一场提前的雷。

然后，我身前的空气皱了一下。

那句话怎么写才合适——一个人凭空出现，其实没有"出现"的过程。前一步那里还是一条空荡荡的林荫道，下一步，他就贴着多特的后心站在那儿了，白得透亮的手指已经扣上了多特的肩。

多特甚至没有来得及回头。

林恩的刀光和我的冰锥是同时到的，全都落了空。那东西揽着多特退到丈许开外——也谈不上退，他只是又"不在"了，再在的时候已在远处。多特的脖颈侧面多了两个血点，血珠子顺着领子往下淌。

"小丫头。"他在那边开口了，嗓音还是那位医师的嗓音，斯斯文文，"你拜的那堆书，烧干净了么？"

我盯着他，一个字也答不出来。视线里，他右手拄着一柄我从没见过的法杖——杖身细长，通体乌沉，像用凝固的夜色削出来的，唯独杖首箍着一轮细细的银环，环里镶的东西不发光，却把日冕那圈惨白的光一丝一丝地吸了进去。

系统叮的一声，这次轻得发颤。

```
📖 图鉴鉴定（强制）
   ⚔️ 「精致的日蚀」
   · 品级：传说
   · 持有者经由它施放的一切魔法伤害，将被转化为「真实伤害」
   · 真实伤害：无视护盾、抗性与一切寻常防御
```

这把杖的来历我此前只当都是吟游诗人的鬼话。眼下鬼话变成了实物，正被握在一个刚刚挣脱了封魔镣铐的血族手里。

多特那边忽然吼了一嗓子。

"小姐！记住他左手的指头缺了根筋——"

那是他的佩剑出鞘的声音。我喊他的名字，喊到一半，喉咙里像被塞了一团冰。这位跟了我几个月、嘴碎得让我嫌烦的年轻侍卫，没有回头看我。他把剑横过来看了一眼，动作干脆得像演练过千百遍——后来我才懂，那哪里算演练，那是每一个给公爵家穿上这身皮的人都上过的最后一课。

剑刃抹过自己的脖颈时，他甚至还朝我这边侧了侧身子，像是怕挡了我的视线，又像是怕我看见。

倒下去的多特没有血可以给他了。图鉴里那行"至濒死之际，可被操控"烧成烙铁印在我脑子里——他用自己的命，把我方还在减少的人数，从敌人嘴边硬生生抠了出去。

"老巴特。"林恩的声音哑得不像她，"护着小姐。"

那天之后的一切，在我的记忆里都是碎的。老巴特和林恩一前一后拿身体把我夹在缝隙里，那东西在四周忽隐忽现；林恩的刀劈不到他，他的黑刃却能从无中生长出来，贴着地皮游过来，像一条闻见血的蛇。我撑开冰墙去挡，墙体在那柄法杖的黑光面前碎得像薄冰——真实伤害无视防御，我的冰在那一轮银环底下等同于一层窗户纸，碎掉的反噬还顺着魔力往我骨头缝里钻。

不能挡，那就只能让他打不中。我把冰凝到路面上去，让整条道化成镜面，逼他落足就打滑；把碎冰撒向半空，赌他瞬移的落点撞上浮冰。这法子替他添了几道小伤口，也把我那点魔力烧去了大半。日冕的光还在一绺一绺往外渗，黑夜赖在正午不走，他的力量就跟着不走。

林恩的手臂挂了彩。老巴特断了一条胳膊，用另一条胳膊往后挪了挪，把我挡得更严。那东西舔了舔杖首的银环，第三次看向我，这回连多余的话都懒得说了。

它消失的瞬间，我脑子里只剩下一个念头：这一次，我连眼睛都跟不上，更别提冰了。

——一只手从我看不到的斜里伸出来，一把攥住了那柄乌黑法杖的杖身。

攥得稳稳的，青筋都爆了出来。

"我说，"来人懒洋洋地开口，声音听起来像刚跟谁问完路，"这么大一把年纪了，还惦记着吃小孩子，羞是不羞？"


◇

雷纳德叔叔是从那东西正身后走过来的。

后来我才知道，他那天是临时起意回家，进城时正撞上广场围观行刑人山人海，他远远地站在人堆尾巴上，看见台上架着的是这么个东西，正觉得哪里不对劲，天就黑了。日蚀一合，人堆里爆出一声喊，那个被缚的影子当着全城的面没了影——只留下一副空荡荡的镣铐和一地碎开的封魔符文。

他只扫了一眼，就猜到了那东西会去哪儿。论腿脚他追不上瞬移，他只是算得准：城里值得一个复仇的血族第一个找上门的人，在回府的哪条路上。

赶得不早不晚。

那东西被攥住法杖的瞬间反手就是一爪，雷纳德偏头避过，爪风在他颊边划开一道血线，他却顺势把整条林荫道变了天——没有征兆，没有咒语，那一带的青石板像被犁头翻过的泥地一样涌动起来，凸的凸，陷的陷，碎石子浮上半空，像一场倒着下的雨。

我起先看不明白这一招的用意，下一瞬就看明白了。

那东西再要瞬移，落点已经没有了。他要出现在哪里，总得先"想"出那个地方的形状，而此刻方圆之内的每一块石头都在挪移，每一粒浮空的碎石都在搅扰他的坐标——雷纳德叔叔把整个战场搅成了一锅浑水。瞬移需要清楚的锚，浑水里落不了锚。

"空间系啊，"雷纳德的声音仍旧懒洋洋的，手上却一招狠过一招，"我在北边也碰见过一个，比你细得多，被我拿雪埋了。"

接下来的拉锯只有几个回合，我却觉得比那一整场日蚀都长。血族弃了杖——法杖被雷纳德攥着脱不了手，他索性松了手，整个人化作一道贴地的灰影往后掠；地面却恰在他后掠的方向上斜斜竖起一堵矮墙。他改掠为跃，浮上半空的碎石轰然合拢，把他罩进一只飞速收紧的石笼；灰影在石笼里猛地涨开，石屑纷飞里窜出来的人形已经残缺了小半边，血红的眼睛里没有恨了，只剩饿——被日蚀喂饱的力量烧完了皮肉，他那点借来的月华，正跟着天光一起退潮。

天上那圈惨白的冕，终于缺开一线。

金红色的日光像一根烧红的针，从缺口里扎了出来，端端正正，钉在这片狼藉的道面上。

他最后扑向的还是我。饿疯了的东西没有仇恨可言，我身上那点方才动武散逸的魔力，在他鼻子里就是最后一餐的香气。可惜他扑到半路，天光大亮——日蚀过去了，正午的太阳重新当空，把他浑身那层暴涨的力量收得干干净净。

雷纳德从斜里赶上，一掌拍进他背心。

那一掌不重。真的不重。我离得那样近，只听见闷沉沉的一声响，像拍碎了一只陈年的空陶罐。灰影在地上滑出老远，再也没有站起来。失去月华的躯壳在真正的阳光底下蜷拢、干裂，最后化成一把灰，风一过，连形状都不剩了。

日头底下，只剩下满地翻倒的石板，断臂的老巴特，撑着刀半跪的林恩，躺在不远处的多特，和一位背着巨大行囊、靴上全是泥的叔叔。

雷纳德弯腰捡起那柄乌黑的法杖，掂了掂，回过头来看我。他脸上还挂着那道口子，血珠子一颗一颗往下坠，可他看着我的眼神里没有玩笑。

"吓着了？"

我摇摇头，又点点头。喉咙里有东西堵着，半天，只挤出一句："多特他……"

老巴特已经蹲过去了，跪在地上，用那条好的胳膊把年轻的侍卫扶正，替他合上了眼睛。这位跟了父亲一辈子的老侍卫什么都没说，可我看见他抹脸的那只手背上全是湿的。

那天的太阳回到了天正中，照得一切纤毫毕现，仁慈得近乎残忍。

◇

善后的事，我没有让任何人代劳。

我把自己关在房间里，把整件事的来龙去脉写在纸上：从外庄的羊，到更夫手腕上的棉布；从月圆的日子，到那一壶始终无人动过的茶；从"以血为引"的旧法子，到那些永远恰好在场的第一诊。写完拿去给父亲看，父亲坐在那里一页一页地翻，翻得很慢，看完抬头看我，看了很久。

"这些东西，你是从什么时候开始串起来的？"

"一开始只是觉得我忘性大，就全往冰晶宫殿里存。"我说，"存在里面的东西不会打折扣，存得多了，它自己会往一处凑。医师那个人哪里都有他，可哪里都称不上错——若没有冰镜替我一趟一趟地看，单凭脑子记，我也只当他热心。"

父亲把纸推回给我，手指在桌沿上敲了敲。

"藏着许多人的那个人，"他半晌道，"是最难找的一种人。你找着了。往后，也要记得今天这一场。"

我说我记得。我会一直记得。这句话说出口的时候，我眼前晃过去的全是多特最后朝我侧过来的那半个身子。

当天晚上雷纳德叔叔来找我。他把那柄乌黑的法杖搁在我桌上，自己往椅子里一坐，先讲了些有的没的，讲北边的雪狼有多大，讲他欠法神的钱越想越亏。讲到后头才转了正题。

"这柄杖，叫精致的日蚀。"他说，"名字花哨，做的是最朴素的勾当——从它这儿打出去的魔法，伤人就是伤人，没有讨价还价的余地。是个惹祸的东西。"

"该上缴吗？"

"该。"他点点头，然后咧嘴一笑，笑完站起身，把法杖往我手里一塞，"所以我琢磨着，缴给你好了。你是我亲侄女，交到你手上，跟缴进公爵府的库房，没什么两样。"

我捧着那柄乌沉的杖。杖身冰凉，杖首那圈银环收拢着光，安安静静的，像一轮缩小的、再也不会咬人的月亮。

"收好它。你如今还使唤不动它，往后也未必用得上——可它认路。"叔叔在我房门口站住，回头冲我摆摆手，"真到了没路可走的时候，让它替你开一条。"

系统的提示音这时候才慢悠悠地响起来，像一场宴席散场后姗姗来迟的账房先生。

```
📜 任务完成
   ✅ 「月下的客人」
   🎁 经验值结算：大幅提升
   🗝️ 传说级物品「精致的日蚀」已存入背包
   · 警告：该物品危险度极高，仅建议在无计可施时取出
```

我把法杖收进背包，看着它在格子里落定，忽然觉得这趟差使从头到尾都像一场早已排好日子的考试。传闻是卷子，冰晶宫殿是草稿纸，而那道最后的压轴题，没有出在书面上。

◇

多特的葬礼，公爵府办得很厚。父亲亲自扶的棺。林恩休了半个月的伤，回岗时左臂上多了一道再也好不了的疤，人也变得更加沉默，只有见到我时，眼神里会多一点我说不清的东西。

老巴特递交了告老的文书，没有递上去——被父亲压下了，说公爵府的侍卫没有老死在外头的规矩。他从此跟着府里的年轻人们操练，偶尔我去花园，还能听见他吼那些半大小子，吼到一半自己先咳嗽。

我呢。我在冰晶宫殿里新存了一面冰镜。画面里没有血，也没有日蚀，只有几个月前回府的路上，阳光正好，一个嘴碎的年轻侍卫跟在我身后，手舞足蹈地比划着，说往后二小姐办案，他多特第一个报名。

画面里的时间是停住的。它就停在那儿了。

有时候我想，记忆这种东西多奇怪——活人把它过成了流水，只有出了事，才知道一段段往回放。我那座宫殿里存着的东西越来越多，明亮的，暖和的，也有那么几面冰镜，我是不敢走近了看的。可即便是那几面，我也一面都舍不得化掉。

毕竟能留住的，也就只有这些了。
